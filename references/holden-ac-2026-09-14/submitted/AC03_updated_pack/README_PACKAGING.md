## Mathematical status

AC-03 is **not yet fully solved** in these materials. The established interval remains `17 <= border rank(M3) <= 20`. The latest work reduces the rank-17 case to an explicit 17-dimensional matrix-space span-limit problem and proves several further obstructions.
