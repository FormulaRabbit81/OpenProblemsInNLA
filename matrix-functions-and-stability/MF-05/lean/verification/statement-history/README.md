# MF-05 statement draft

The complete original target is local two-family Hölder continuity of the joint spectral radius with exponent 1/d for arbitrary nonempty compact complex matrix families. This package contains concrete definitions and 14 independent Challenge obligations. It contains no MF-05 proof implementation and makes no Lean-elaboration, Comparator, independent-review, freeze or completion claim.

Read [Definitions](NLA/MF05/Definitions.lean), [Challenge](Challenge.lean), [the exact contract map](CONTRACT-MAP.json), [source correspondence](SourceCorrespondence.md), [reuse audit](REUSE-AUDIT.md) and [the numerical boundary](NUMERICAL_TARGETS.md). The final contract uses the original max-of-sup-inf spectral Hausdorff formula. The mandatory semantics contracts connect it to Mathlib's operator-image Hausdorff metric and connect the actual positive-index-root infimum to the original root limit, including radius zero.

All 20 NLA.MF07 modules are copied unchanged from published upstream 5308b2cfa30826e1314d6a8830415c14b5f1d7a3 and retain their namespace and authorship. Their radius-one comparison is reused through new explicit general-root, scaling and scalar-identity obligations. No extremal-norm, continuity, compactness or minimizer oracle is built into a definition. Infinitely many generators, reducibility, zero radius, zero distance and dimension one remain included.

Lean 4.33.1, Mathlib 0df444a360eaa60ab8c11dca51a86af692955474 and LeanCert 621a43d7cf21f87872392a01e874f2f1dbddc926 are pinned. The fresh root package name is NLAMF05; every dependency-manifest entry is unchanged from the retained published MF07 manifest. The shared dependency source HEADs were checked, but no .olean or other cached compiler output was authenticated or used by this drafting task.

The current Lake default is Challenge for future statement elaboration. comparator.json reserves the future Solution module and all 14 exact exports; Solution.lean is absent. Intentional Challenge placeholders are excluded from metadata's proof-development sorry count, and their separate count is 14. A schema/coverage PASS means metadata consistency only; it is not a proof or Comparator result. New transitive axioms are unmeasured and are not represented as an empty or successful axiom result.

Root controls all local Lean execution with one compiler, one thread and a 4096 MiB limit. Two independent nonauthor reviews of the actual statements and root-controlled elaboration/freeze must precede new MF05 proof bodies. Final verification requires actual non-root Linux GitHub Comparator/default-kernel/axiom/sandbox/rejection checks after local proof success. Solution must never import Challenge. The only planned new numerical certificate is 0 < 1/2 < 1, using kernel-mode LeanCert and actually consumed by the common norm-ball construction and final positive local radius. Dimensions, words, radius limits, perturbation bounds and real-power optimization remain symbolic. The sharper scalar constant and sharpness examples are outside this formal target.
