This is a candidate package for the permanent path
`intervals-and-absolute-value-equations/IV-03/lean`. No Git branch, commit, push,
pull request, canonical status change, or accepted-count change is made here.

fetched directly from the immutable GitHub Git tree/blob API. Git blob hashes,

tree responses contain no contact metadata and are retained unmodified.

and seven historical consumer/audit files. The thirteen-file Solution closure,

records, numerical plan, license and dependency pins are unchanged. The
original build already defaults to Solution. No new mathematical files or
build-configuration changes were introduced.

integration attribution and pending-run status; their exact original bytes
remain under `before/`. Additional files are documentation, source bindings,
the bounded independent review selections, historical evidence, and static

is copied unchanged. The optional extra copy of Colbrook's complete manuscript

The schema/coverage check and [package audit](PACKAGING-CHECKS.json) are Python
checks, not Lean runs. With the Python requirements installed, the audit can be
reproduced from this directory using:

```sh
python3 -B audit_package.py
```

`fetch_original.py` is the initial immutable-source acquisition script, intended
for an empty candidate directory before integration metadata is changed.
`prepare_integration.py` records the evidence-copying and attribution operations
used in this environment. Neither executes Lean or mutates Git. The copied
metadata validator and pinned schema retain their original license/provenance.

The package manifest seals the files actually retained. The separate original
review manifests describe their larger historical review packets and do not
assert that omitted private authentication material is published here.
