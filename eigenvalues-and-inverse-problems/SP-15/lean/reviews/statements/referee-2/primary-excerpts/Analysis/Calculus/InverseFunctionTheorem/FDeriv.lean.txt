62: ### Inverse function theorem
63: 
64: Let `f : E → F` be a map defined on a complete vector
65: space `E`. Assume that `f` has an invertible derivative `f' : E ≃L[𝕜] F` at `a : E` in the strict
66: sense. Then `f` approximates `f'` in the sense of `ApproximatesLinearOn` on an open neighborhood
106:       f'.subsingleton_or_nnnorm_symm_pos.imp id fun hf' => half_pos <| inv_pos.2 hf'
107: 
108: variable (f)
109: variable [CompleteSpace E]

111: /-- Given a function with an invertible strict derivative at `a`, returns an `OpenPartialHomeomorph`
112: with `to_fun = f` and `a ∈ source`. This is a part of the inverse function theorem.
113: The other part `HasStrictFDerivAt.to_localInverse` states that the inverse function
114: of this `OpenPartialHomeomorph` has derivative `f'.symm`. -/
115: def toOpenPartialHomeomorph (hf : HasStrictFDerivAt f (f' : E →L[𝕜] F) a) :
116:   OpenPartialHomeomorph E F :=
117:     ApproximatesLinearOn.toOpenPartialHomeomorph f
118:     (Classical.choose hf.approximates_deriv_on_open_nhds)
119:     (Classical.choose_spec hf.approximates_deriv_on_open_nhds).2.2
120:     (f'.subsingleton_or_nnnorm_symm_pos.imp id fun hf' =>
121:       NNReal.half_lt_self <| ne_of_gt <| inv_pos.2 hf')
122:     (Classical.choose_spec hf.approximates_deriv_on_open_nhds).2.1
123:
