The finite Schur recursion proves the full maximal-subspace factorization. Scalar polynomial factorization preserves repeated and boundary roots. Complex gradient convexity, real separation and a uniform descent argument produce a norm-attaining orthogonal vector; the affine minimax theorem then transfers to the actual upper Jordan block through reversal. Zero, empty and dependent directions are included in the supporting contracts. No interpolation or minimax theorem is assumed as an oracle.

The positive-half bound is proved using genuine kernel-mode LeanCert and consumed by the symbolic descent bounds. Root selection, factorization, matrix norms and extrema are proved symbolically. There is no interval grid or sampled assertion.
