They are UNRUN. Root alone owns the serial local compiler; independent proof
review and the final GitHub Comparator are pending. This packet makes no
finite-Schur, minimax, canonical-target completion or counting claim.

The numerical/symbolic plan predates both sources; its original PLAN ONLY
wording is retained as the historical record. The root acceptance and the
pre-implementation binding check record the later implementation authorization.

SchurEndpoint exhausts the first column's squared Euclidean norm. It proves
only the vanishing of coefficients visible below the diagonal, never that the
unbounded polynomial symbol is constant. The scalar action, existing maximal
space norm characterization and coefficient roundtrip then supply every
SchurPair clause, including denominator nonvanishing, exact numerator degree,
coprimality, full subspace parameterization, action and dimension.

SchurActiveBlock uses divX for its exact Toeplitz witness. The first row and
last column vanish, giving the stated append-input/prepend-output action.
Five small coordinate helpers expose the squared norm, norm-preserving zero
embeddings and decomposition of every input. Both operator-norm inequalities
work at n=0. Contractivity is used to force the final input coordinate to zero
in the saturation equivalence.
