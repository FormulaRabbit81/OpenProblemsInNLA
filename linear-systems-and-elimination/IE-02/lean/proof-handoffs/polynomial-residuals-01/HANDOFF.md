Two UNRUN candidates implement exactly frozen contracts 47 and 49. The root
approved the numerical/symbolic plan before either source existed. That plan,

finite affine matrix-power residual correspondence for arbitrary matrices,
then specializes it to the frozen lower-Jordan family. It also proves the
value-set equality by explicit witnesses in both directions. GMRESSemantics
applies sInf to those proved set equalities, reuses both affine minima, and
transports actual polynomial witnesses with universal minimality. The unit
vector bound uses the actual continuous Euclidean operator norm.

frozen headers, actual static checks and primary API bindings are supplied.

local Lean checks, inspect both axiom/trust outputs and arrange independent
